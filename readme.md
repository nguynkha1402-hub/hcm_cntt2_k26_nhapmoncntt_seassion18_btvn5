### Phần 1. Phân tích

Vai trò JSON Viewer: Chuyển đổi dữ liệu API thô thành cấu trúc cây phân cấp có tô màu cú pháp, giúp kỹ sư đọc hiểu và gỡ lỗi nhanh chóng.

### Phần 2. Triển khai

-5 Tiện ích cốt lõi:

- Dev Suite: JSON Viewer Pro, Talend API Tester.
- Productivity: ColorZilla.
- Security: uBlock Origin, Privacy Badger.

-Thao tác thiết lập: Ghim tiện ích lên Toolbar. Chuột phải vào từng tiện ích > Quản lý tiện ích > Đổi Site access thành On click để bảo mật dữ liệu luồng xe và tối ưu RAM.

### Phần 3. Kiểm thử

Nếu biểu đồ Waterfall gây lag, truy cập `chrome://extensions/`, tắt toàn bộ và bật lại từng tiện ích để tìm thủ phạm.

Nhấn `Shift + Esc` mở Chrome Task Manager, kiểm tra cột Memory footprint để xác định chính xác tiện ích nào đang ngốn RAM.
